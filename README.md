# Urban Transportation Website

## Project Title

Urban Transportation Website

## Purpose of Website

This website is designed to provide users with smart and easy transportation information. Users can explore transportation services, routes, and city travel facilities through a simple and interactive interface.

## Technologies Used

* HTML
* CSS
* JavaScript

## Main Features

* Responsive Design
* Navigation Menu
* Explore Routes Section
* Interactive Buttons
* Route Planning Form
* Smooth Scrolling
* User Friendly Interface

## Website Flow / Working

Users can open the homepage and navigate through different sections of the website. They can explore transportation services, check routes, and interact with buttons and forms. The website works smoothly on desktop and mobile devices.

## Conclusion

This project demonstrates frontend web development skills using HTML, CSS, and JavaScript to create a modern and responsive transportation website.
